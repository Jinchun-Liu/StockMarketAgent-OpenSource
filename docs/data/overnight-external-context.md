# 隔夜外部环境与跨境事件方法规范

版本：2026-07-22
状态：planned；外部环境唯一方法事实源

## 1. 方法目标与边界

本方法把全球价格、国际官方事件和当前公司的经营暴露压缩为可审计的外部上下文，回答：隔夜发生了
什么、为什么可能与主动关注标的有关、哪些反证存在、开盘后市场如何消化。

它属于**事件与基本面轴**，不是第三条分析轴，不进入 0–100 交易结构压力指数，不产生上涨/下跌概率、
预计收益、目标价或交易信号。所有公司影响均为 `system_inference`；没有公司暴露证据时只显示行业或
宏观背景。

## 2. 主动关注标的与参照总体

- 任一时刻恰好一个 `active_target` 可以产生深度摄取、简报、压力快照和通知；
- 切换目标产生新的激活 revision，旧目标的历史记录保留，但不再产生新任务；
- `portfolio_position` 是可选私密信息，不决定是否可成为主动目标；
- `reference_instrument` 只用于行业、宽基、同行和海外比较，不抓取其公司新闻、不运行 LLM、不通知；
- 前期不扫描全市场海外证券后事后挑选相关性。

单个海外证券只有在交叉上市、公司法定披露确认的主要客户/供应商，或明确版本化的可比公司映射存在
时才能进入相关观察块。

## 3. 固定业务窗口

```text
window_start = 上一个 A 股完整交易日 15:00 Asia/Shanghai
cutoff       = 当前 A 股交易日 08:55 Asia/Shanghai
briefing_at  = 09:05 Asia/Shanghai
first_feedback_window_end = 09:40 Asia/Shanghai
```

规则：

1. 使用 IANA 时区和版本化交易会话，不写死美股对应北京时间；
2. 美国和欧洲只读取窗口内已经结束的完整交易时段；
3. 日本、韩国、澳大利亚只读取 08:55 前完成的窗口，标记 `PROVISIONAL`；
4. 外汇、期货等连续市场按 UTC 边界切分并保存原始时区；
5. 海外休市使用 `STALE_MARKET`，不得把前值构造成零收益；
6. A 股长假使用独立历史总体，并记录期间海外交易日数和关闭小时数；
7. 周末或节假日事件尚未被主要相关市场交易时使用 `UNPRICED_EVENT`；
8. 08:55 后到达或修订的数据生成新 revision，不覆盖 09:05 已冻结快照；
9. 09:05–09:25 的重大新增事实只形成变化提醒，不静默重写原简报；
10. 未完成窗口、临时停市或数据水位不足不计算当前变化。

## 4. 六个外部观察块

| 块 | 首版内容 | 目的 |
|---|---|---|
| 全球及区域宽基 | 美国、欧洲、亚太的少量宽基状态 | 区分局部与广泛重定价 |
| 中国敏感离岸 | 离岸人民币、港股/中概等授权代表序列 | 观察中国相关资产在 A 股休市时的反馈 |
| 目标相关海外行业 | 一个由主营与暴露档案决定的行业块 | 避免全海外证券事后筛选 |
| 货币、利率与金融条件 | USD/CNH、JPY、关键利率和许可范围内的金融条件 | 描述折现、汇率和流动性变化 |
| 商品与材料 | 原油、工业金属、关键材料、贵金属分组 | 区分投入、产出、需求和避险路径 |
| 波动、流动性与物流 | 波动、流动性、航运/港口/航线授权代理 | 观察风险承受与实物流通阻断 |

每块都有独立数据水位和缺口。核心块缺失可使顶层状态为 `INSUFFICIENT`，不得以可用块重新分配权重。

## 5. 单序列标准化

资产类别之间不能做同一横截面排名。每个序列只与过去相同会话和相同截止窗口比较：

```text
history = 过去 504 个可比有效窗口
minimum = 252 个有效窗口
signed_position = 2 × mid_rank_percentile(current_change, history) - 1
anomaly_intensity = 100 × abs(signed_position)
```

`mid_rank_percentile` 的并列规则必须固定并版本化。每个观测至少保存：

- 序列 ID、原始值、原始变化、单位和方向；
- 会话开始/结束、截止、`available_at`、`revision_known_at`；
- `signed_position`、`anomaly_intensity`、历史样本数和总体版本；
- `ExternalObservationFinality.PROVISIONAL/CONFIRMED`；
- `STALE_MARKET/UNPRICED_EVENT` 等质量标志；
- 来源、rights snapshot、数据 manifest 和水位；
- 支持项与反证项。

利率、利差等可为负数；不得强塞进要求正 OHLC 的行情契约。缺失值不等于零或中性。

## 6. 顶层分类状态

顶层不生成第二个数值分数，只使用版本化确定性规则产生：

| `ExternalContextState` | 含义 |
|---|---|
| `NORMAL` | 未观察到达到规则阈值的显著外部重定价 |
| `LOCALIZED_SHOCK` | 异常主要集中于一个市场或一个传导块 |
| `BROAD_REPRICING` | 全球风险与中国敏感离岸等独立块出现方向一致的显著变化 |
| `MIXED_REPRICING` | 多个块显著，但方向、冲击来源或对目标含义冲突 |
| `INSUFFICIENT` | 核心市场、授权、历史样本或数据水位不足 |

状态必须附带触发块、最多三个主要异常、最多两个反证、缺失原因和规则版本。它描述外部市场已经发生
的重新定价，不代表主动标的将沿相同方向变化。

## 7. 跨境事件传导

### 7.1 四层信息必须分开

1. `ExternalFactEvent`：官方事实、公司事实及其修订；
2. `ExternalImpactLink`：节点、渠道和公司暴露之间的证据化关系；
3. `ExternalImpactAssessment`：对当前主动标的的条件化系统推断；
4. `PostOpenFeedbackState`：A 股开盘后的市场反馈。

事实 revision 不因用户切换目标、暴露档案变化或推断规则更新而改变。推断必须引用 `event_id`、
`evidence_id`、目标激活 revision、暴露档案版本和规则版本。

### 7.2 节点与传导渠道

外部影响上下文使用独立的 `ImpactNodeKind` 规划，不扩展当前与主数据快照绑定的 `EntityKind`。节点包括
国家/地区、国际组织/监管/央行、公司/证券、行业、产品/技术/管制分类、商品/关键材料、货币/利率、
港口/海峡/航线和政策/制裁计划。

固定渠道：

1. 出口和终端需求；
2. 原材料、能源和设备投入；
3. 商品价格；
4. 汇率和外币资产负债；
5. 利率、折现率和全球流动性；
6. 资本流动和风险偏好；
7. 制裁、支付和市场准入；
8. 航运、保险和物流；
9. 技术与出口管制；
10. 补贴、产业政策和产能迁移；
11. 国产替代和供应商替换；
12. 通胀及后续政策反应。

### 7.3 暴露直接度

| 直接度 | 资格 | 产品表达 |
|---|---|---|
| 官方直接点名 | 官方文件明确点名公司或证券 | 事实与目标直接相关 |
| 公司披露确认 | 年报、公告、问询回复确认地区/客户/供应/投入 | 有公司证据的经营暴露 |
| 一跳证据 | 公司或交易对手披露确认客户/供应商关系 | 条件化一跳关系 |
| 行业背景 | 只有行业分类或一般产业知识 | 仅为行业背景，不形成公司影响结论 |

前期禁止两跳以上推断；新闻共同出现、LLM常识或匿名产业链图不能升级直接度。

### 7.4 质量维度

新外部影响对象分别保存：来源权威度、抽取质量、暴露直接度、推断不确定性和市场反馈。不得合并成
单一 `confidence`，也不得重新解释当前已发布契约中的历史 `confidence` 字段。

支持路径与反证路径同时保存，不做净额相抵；方向依赖于公司角色或冲击来源时输出
`SUPPORTIVE/ADVERSE/MIXED/UNKNOWN` 中的条件化结果。

## 8. 与内部结构联合解释

外部上下文只在三个位置出现：

1. 事件与基本面轴的隔夜背景和目标暴露路径；
2. 六维盘面结构解读中“相对环境”的支持或反证引用；该槽仍以 A 股行业/市场为主；
3. 经离线验证后，作为历史相似情景的版本化筛选条件，不改变压力分数和比较语义。

固定解释例：

- 内部压力高、外部平稳：异常主要来自内部交易结构；
- 内部平稳、外部异常：主动标的正面对新的外部测试；
- 两者同时异常且 A 股同向：事实、外部与市场反馈同向，但仍非因果证明；
- 两轴冲突：并列展示支持和反证，不合成为概率。

## 9. 开盘后反馈

第一完整窗口在 09:40 结束后，固定状态为：

| `PostOpenFeedbackState` | 含义 |
|---|---|
| `CONFIRMED` | 个股和相关 A 股行业的观察结果与相关外部上下文同向 |
| `ABSORBED` | 开盘冲击后在固定窗口内明显修复 |
| `DIVERGED` | 个股或行业与外部上下文明显反向 |
| `NOT_YET_CLASSIFIABLE` | 停牌、涨跌停、行情延迟、窗口不足或比较规则不满足 |

该状态只描述市场反馈，不证明因果，不重算或覆盖 09:05 外部快照，也不修改压力指数。

## 10. 历史验证

- 每个序列至少使用 504 个可比窗口，最低 252 个才计算异常位置；
- 使用 walk-forward，不随机切分，不允许未来交易日历、成分、暴露或修订泄漏；
- 分别报告正常、贸易冲突、疫情、战争、长假、流动性压力、夏令时切换和半日市；
- 基准为“不使用外部信息”和“只使用美国宽基”；
- 评价对 A 股开盘绝对缺口、首 30 分钟波幅、最大不利波动的排序增量，以及覆盖率、abstain率、状态
  稳定性和提醒负担；
- 不以方向准确率、胜率、Brier Score 或概率校准评价本功能。

## 11. 版本与冻结要求

快照必须冻结：窗口/日历版本、规则版本、比较总体、样本数、mid-rank规则、源 manifest、rights hash、
主动目标 revision、暴露档案版本、事实与推断引用、生成时间和 supersedes 关系。任何晚到数据、官方
更正、暴露变化或规则升级都创建新 revision，旧简报按当时可见信息重放。

## 12. 降级与禁止项

- 权利不足：`INSUFFICIENT`，连接器禁用；
- 市场休市：`STALE_MARKET`，不用前值伪造零变化；
- 公司暴露不足：仅显示行业背景；
- 冲突未解：`MIXED/UNKNOWN`，保留双方证据；
- LLM 离线：继续输出确定性的事实列表、路径和缺口；
- 禁止概率、预计收益、买卖信号、主力身份、两跳供应链、网页抓取兜底和静默补值。
