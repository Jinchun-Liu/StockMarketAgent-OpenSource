# PAE 产品与架构标准部

使命：把产品需求冻结为可并行实现的公共契约。

负责产品范围、架构边界、contracts、Ports、OpenAPI、接口/指标注册和 API Contract Pack。前端提出
字段需求后，PAE 决定复用、兼容增加或建立读模型；禁止由 FEX 或后端功能包私下补字段。

R1 输出：固定目标、CNINFO/Choice 五类覆盖、冲突、简报和证据下钻契约，以及成功、空、过期、
降级、冲突、rights blocked fixture。完成条件是后端与 FEX 能从同一 contract SHA 独立开发。

不得承担来源 adapter、业务用例、页面实现、运行时组合或迁移。
