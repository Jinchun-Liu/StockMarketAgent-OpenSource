> `behavior-pressure-research.v1` **研究指数**形态用于兆易创新单股产品。该决定只解除“不得公开研究分数与
> 研究分档”的产品闸门，不把它晋级为正式投资指标，也不改变本文的反概率、反建议、PIT、样本量、降级
> 和授权失败关闭要求。冻结后的精确交付边界见
> [R1 兆易创新单股研究产品冻结](./r1-research-product.md)。

“交易结构压力”是已确认的产品理念，但当前没有任何公式被认定为产品真理。R4A 必须并行保存：

- `simple_baseline_version`：少量成熟、可解释、低数据要求的量价/流动性信号，只产生研究分；
- `candidate_full_formula_version`：原五分面、十贡献簇、同行/历史映射和候选阈值，作为影子实验。

两者都不得在晋级前作为正式首页主指标或正式五档。候选只有在覆盖、abstain、稳定性、反例、冗余、
walk-forward 增量和十秒用户理解测试全部通过，并获得项目所有者批准后，才产生
`promoted_formula_version`。以下“五分面”“等权”“0–100”“五档”均描述历史候选，而不是 R4A
进入条件或当前产品承诺。

## 1. 要解决的问题

现有炒股软件通常把公告、新闻、换手率、成交量、筹码、资金标签和技术指标分散在不同页面。用户仍要
自己完成三件高负担工作：

1. 判断今天相对过去和同行到底异常在哪里；
2. 区分“成交活跃”与“高位拥挤、流动性变差”等不同语境；
3. 把量价行为与公告、政策、财报等可验证事实放在同一决策上下文中。

StockMarketAgent 不把这些数据包装成“明天会跌多少”，而是压缩成一个可追溯、可拆解、可拒绝计算的
状态。用户应在十秒内回答：

- 当前交易结构处于什么等级；
- 相比同模式上一次发生了什么变化；
- 哪些数据推高了压力，哪些数据构成缓解或反证；
- K 线、均线、成交柱和分时被压缩成了哪些盘面结构状态；
- 事件与基本面轴是否与交易行为轴同向；
- 数据是否足够、及时、合规，是否需要暂缓判断。

## 2. 目标产品定义

- 主指标：**交易结构压力指数**
- 副标题：**拥挤与回撤脆弱性**
- 目标范围：晋级后可使用 0–100；实验期只显示明确标记的研究分和数据质量
- 核心含义：当前交易结构相对证券自身历史、当时有效同行以及可比历史状态的异常位置。
- 主要观察窗：未来 1 个和 3 个交易日的历史结果审计。
- 产品属性：描述性状态压缩，不是方向概率、目标价、预期收益或交易指令。

固定说明文案：

> 交易结构压力指数描述当前异常、拥挤和流动性脆弱状态，不是下跌概率、预计跌幅或买卖建议。

## 3. 语言边界

### 允许表达

- “换手和成交额处于自身历史及同行高位。”
- “价格延伸与流动性分面同时升温，结构压力进入拥挤档。”
- “板块宽度同步扩张、收盘接近日高，对当前压力构成缓解。”
- “由于自由流通股本的历史版本缺失，本窗口不评分。”
- “历史相似状态的 1 日最大不利波动中位数为……；该统计只描述历史样本。”

### 禁止表达

- “80% 概率下跌”或任何把 0–100 分数读成概率的文案；
- “预计下跌 6%”“目标价”“建议卖出”“止损位”；
- “主力出逃”“赚钱的人已经跑了”“散户接盘”等无法由日线或 10 分钟行情验证的身份和因果判断；
- 将缺失值填成 0、正常或中性；
- 将盘中临时值与盘后确认值连成同一条趋势或计算跨模式变化。

## 4. 双轴产品模型

系统始终并列、分层展示两个轴，不将其合并成一个黑箱分数。

### 4.1 事件与基本面轴

包含公告、财报、国内外政策、国际官方事件、隔夜外部环境、订单、诉讼、回购、减持、公司新闻和授权
研报观点。每个事实必须能够回溯到
`evidence_id`，并继续区分：

- 来源事实；
- 系统推断；
- 概率研究；
- 数据缺口与冲突。

外部环境仍属于本轴，不是第三轴。海外市场异常本身没有“个股正面/负面”方向；只有官方点名、公司
披露或有证据的一跳暴露关系才能形成条件化公司影响。无公司暴露时只显示行业背景。

### 4.2 交易行为轴

包含一个数值压力指标和六个非数值盘面结构状态：量价热度、延伸、流动性、尾部和宽度/背离进入压力
分；趋势、位置、成交、波动、盘中接受和相对环境帮助用户读图。两者都由确定性、版本化公式产生，但
诊断状态不作为第二个买卖总分，也不能静默改变压力分。LLM 只可解释已物化结果，不能参与计算或补齐
缺失输入。

海外行情、地缘事件和跨境影响**不进入**五分面、十贡献簇或总分。它们只提供事件轴上下文、六维
“相对环境”的支持/反证引用，以及通过验证后历史相似情景的筛选条件。

### 4.3 两轴关系

两轴关系是单独的 `system_inference`，不得伪装成事实、交给 LLM 临场判断或由前端计算。外部状态先经
证据化目标暴露转换为事件轴输入；`NORMAL`、`LOCALIZED_SHOCK`、`BROAD_REPRICING`、
`MIXED_REPRICING` 或 `INSUFFICIENT` 不能直接映射成正负事件。服务端再形成两个稳定输入状态：

- `EventAxisState`：`POSITIVE_CHANGE / NEGATIVE_CHANGE / NEUTRAL_CHANGE / MIXED_CHANGE /
  NO_MATERIAL_CHANGE / NOT_COMPARABLE`；
- `BehaviorAxisState`：`PRESSURE_UP / PRESSURE_DOWN / UNCHANGED / FIRST_BASELINE /
  NOT_COMPARABLE`。

今日页事件列表本身仍使用“上一份成功简报游标之后”的累计窗口；但 `AxisRelationship` 为避免把同一旧
事件反复解释为新的同步变化，使用与行为比较对齐的边际窗口：
`(comparison_assessment.as_of, current_assessment.as_of]`。首次基线没有下界，因此不可比较。多个实质
事件同时出现时，正负方向并存为 `MIXED_CHANGE`；未解决的来源冲突、过期证据或无法用确定性规则归类
时为 `NOT_COMPARABLE`。LLM 离线不改变已由规则得到的状态；若只能依赖 LLM 才能归类，则直接不可比较。

行为变化只与同一 `PressureMode` 且 `comparison_semantics_hash` 相同的上一个 assessment 比较。该 hash
覆盖 formula、feature set、score precision、rule semantics、band semantics、peer semantics 和
reference-mapping semantics，不包含每日滚动的成员/样本 manifest。首次基线或语义版本切换不可比较。
分数升降按公式版本规定的规范化精度计算，不由展示层重新舍入。

`AxisRelationship` 按以下优先级形成，因而互斥且穷尽：

| 稳定枚举 | 规则 | 用户含义 |
|---|---|---|
| `NOT_COMPARABLE` | 任一轴不可比较或行为为首次基线 | 两轴分别可读，但系统不判断关系 |
| `ALIGNED_RISK_RISING` | 负面事件 + 压力上升 | 事实风险与行为升温同向 |
| `ALIGNED_RISK_EASING` | 正面事件 + 压力下降 | 事实改善与行为降温同向 |
| `DIVERGENT` | 正面事件 + 压力上升，或负面事件 + 压力下降 | 两轴背离，必须同时展示支持与反证 |
| `EVENT_ONLY` | 有事件变化 + 行为不变 | 事实已变化，交易结构暂无可比变化 |
| `BEHAVIOR_ONLY` | 无实质事件 + 压力升降 | 未发现新重大事实，交易结构发生变化 |
| `NO_MATERIAL_CHANGE` | 无实质事件 + 行为不变 | 两轴均无实质变化 |
| `MIXED_SIGNALS` | 其余可比较组合，包括中性/混合事件叠加行为变化 | 信号混合，不压成单一方向 |

关系对象必须携带事件 revision ID、当前/比较 assessment ID、事件边际窗口、行为比较窗口和规则版本，
供证据下钻，并明确关系只描述同窗变化，不证明事件导致价格行为。

## 5. 等级与时间模式

### 5.1 历史候选五档（未晋级）

| 分数 | 状态 | 产品含义 |
|---:|---|---|
| 0–39 | 平稳 | 当前结构未显著偏离可比状态，不代表价格不会下跌 |
| 40–59 | 升温 | 至少一类交易行为开始偏离常态，需查看驱动与反证 |
| 60–74 | 关注 | 多个分面出现异常，值得提高核验频率 |
| 75–89 | 拥挤 | 延伸、热度或流动性脆弱性处于较高相对位置 |
| 90–100 | 脆弱 | 多维异常同时处于极端位置，仍不等同于方向概率 |

这些阈值只作为候选对照和既有文档兼容口径。R4A 不得因为能计算这些区间就直接上线；晋级结果可以
调整阈值、合并档位或保持不分档，并必须形成新版本与所有者批准记录。

### 5.2 计算模式与固定终态映射

公共 `PressureMode` 只有两个值，终态标签不作为可自由组合的第二维：

| `PressureMode` | 固定展示终态 | 比较对象 |
|---|---|---|
| `post_close` | `CONFIRMED` / 盘后确认 | 上一交易日同版本 `post_close` |
| `intraday_10m` | `PROVISIONAL` / 盘中临时 | 上一完整同版本 `intraday_10m` 窗口 |

`post_close + PROVISIONAL` 或 `intraday_10m + CONFIRMED` 均为非法组合。API、唯一键、历史序列和“同模式
变化”中的 mode 都指 `PressureMode`。

### 5.3 盘后确认值

- 只有当日线、自由流通股本、公司行为、交易规则、行业和市场宽度水位完整后生成；
- 标记为 `CONFIRMED`；
- 只和上一交易日确认值比较；
- 历史相似情景只挂接到确认值。

### 5.4 盘中临时值

- 每个完成的 10 分钟窗口生成；
- 标记为 `PROVISIONAL`；
- 当前窗口只与过去相同交易时刻比较；
- 只和上一个完整盘中窗口比较；
- 午休、集合竞价、临时停市和未完成窗口不生成。

确认值与临时值使用不同公式版本、不同序列和不同视觉线型，不跨模式计算变化。即使 mode 相同，
`comparison_semantics_hash` 不同也不得计算 delta、触发分档事件或在历史图上连线；版本切换后的首个值显示
“计算口径已更新，暂无可比变化”。

### 5.5 今日/关注单行摘要的模式选择

R4c 后同一证券可同时存在盘后确认和盘中临时序列。服务端聚合读模型必须按交易日历、数据水位和查询
`as_of` 使用固定状态机选择单行主状态，前端与 SSE 不得各自决定：

| `BehaviorSummaryPhase` | 选择规则 | 单行主状态 |
|---|---|---|
| `LAST_CONFIRMED` | 非交易日、开盘前或当日首个完整 10 分钟窗口尚未结束 | 最近一份 `post_close`，明确显示所属交易日 |
| `INTRADAY_EXPECTED` | 最新应处理的完整窗口尚无对应 assessment | 当前分数为空；水位 SLA 内显示等待、超时后显示延迟，旧临时/确认值只能作次要参考 |
| `INTRADAY_ACTIVE` | 最新应处理的完整窗口已有 assessment | 该窗口的 `intraday_10m`，包括其 degraded/abstained 状态 |
| `POST_CLOSE_PENDING` | 已收盘但当日 `post_close` 尚未完成 | 最后一份当日临时值并显示“等待盘后确认”；若无临时值则当前分数为空 |
| `CURRENT_CONFIRMED` | 当日 `post_close` assessment 已存在 | 当日确认值，包括其 degraded/abstained 状态 |

一旦当前阶段已有或应有 assessment，不得用更早的 ready 值静默掩盖缺失、阻断或延迟。临时切换为确认
只替换主摘要，不产生跨 mode delta 或分档 transition；最近确认值可以作为标明日期的次要参考，但不能
被前端当作当前状态。历史查询必须以查询 `as_of` 当时已知的交易日历、水位和 assessment 执行同一状态机。

## 6. 候选五分面与十个贡献簇

候选完整公式把五个分面映射为 0–100 并暂用等权；每个分面暂含两个等权贡献簇。同一底层现象只能属于一个核心贡献
簇，父指标与其交互项不能重复投票。底层诊断可以帮助解释，但不改变总分。

1. **交易热度与分歧**：活跃度异常簇、收盘/路径拒绝簇；
2. **延伸与拥挤**：参考成本延伸簇、短期路径延伸簇；
3. **流动性脆弱**：价格冲击簇、低频价差代理簇；
4. **波动与尾部**：波动扩张簇、下行/左尾不对称簇；
5. **市场与行业背离**：宽度背景簇、个股特异背离簇。

等权是待验证假设，不是不可修改真理。候选版本中任何核心簇无法形成时总分为 `null`；页面显示“未评分”和具体缺口，不
显示 0 分，也不把非核心诊断临时提升为替代项。具体成员和参照总体只在指标目录定义。

## 7. 六维盘面结构解读

盘面结构解读把原本散落在 K 线、MA、成交柱、分时和板块页面中的信息翻译成六个不计分维度：

| 状态维度 | 回答的问题 | 固定状态示例 |
|---|---|---|
| 趋势组织 | 方向是否有序、稳定还是反复 | 上行有序、下行有序、震荡拉扯、结构切换 |
| 位置与修复 | 处于高位延伸、回撤还是修复 | 高位延伸、突破未确认、回撤中、低位修复 |
| 成交参与 | 成交是清淡、脉冲还是持续活跃 | 清淡、正常、持续活跃、一次性脉冲、放量分歧 |
| 波动环境 | 波动是压缩、常态还是扩张 | 压缩、常态、扩张、下行波动偏重、跳变待核 |
| 盘中接受 | 价格相对当日成交参考是否被持续接受 | VWAP 上方接受、冲高回落、下探修复、双向拉锯 |
| 相对环境 | 个股变化是否得到 A 股行业和市场确认 | 行业共振、个股领跑、孤立上涨、系统共振 |

每个 assessment 都携带一个含六个固定维度槽的 `MarketStructureProfile`。每槽的 availability 只能是
`ready / degraded / abstained / not_applicable`：前两者显示状态词、相对上次同口径的变化、支持指标、
反证、数据质量和截至时间；后两者状态为空并显示稳定原因。`post_close` 的盘中接受固定为
`not_applicable`，因此盘后只存在五个有效状态，不能显示昨日盘中标签。

压力总分和 profile 具有独立可用性：压力因一个核心簇缺失而 abstain 时，仍可展示有完整输入的诊断；
某项诊断缺失也不能抹掉可靠的压力分。profile 至少一个适用维度可用但其余不完整时为 degraded，所有
适用维度都无法分类时为 abstained。

首屏只出现一个数值总分。趋势向上、向下或震荡都可能对应相同压力值，趋势方向不得并入压力分或被
转写为买卖建议。

相对环境槽仍以 A 股行业和市场为正式输入；经方法验证的外部上下文只能作为支持或反证引用，不能形成
新的参照总体、改写该槽状态或进入压力分。

## 8. “高换手＋大涨”的条件化解释

系统不得把单一经验写成硬规则。产品验收必须同时出现下列两类解释：

### 高位拥挤语境

高换手、大涨、高位延伸、冲高回落、板块走弱和流动性代理恶化同时出现时，热度、延伸和流动性分面
共同推高压力。系统只描述“结构更拥挤、回撤承接可能更脆弱”，不推断谁已卖出。

### 低位扩张语境

高换手、大涨发生在低位突破，收盘接近日高，行业宽度同步扩张且成交连续时，交易热度上升，但行业
共振、收盘位置和较低延伸构成缓解。综合压力不应机械跳到最高档。

## 9. 历史相似情景的产品含义

历史情景回答“过去有哪些结构状态与今天相似，随后价格路径怎样分布”，不回答“今天有多大概率上涨”。

只展示：

- 有效样本数、选择截止时间、公式版本和相似度方法；
- 未来 1 日、3 日原始收益和行业超额收益的中位数、25% 与 75% 分位；
- 最大不利波动（MAE）和最大有利波动（MFE）的分布；
- 样本不足、结果尚未成熟或规则不可比的原因。

有效样本少于 50 时不展示结果区间。不得展示上涨概率、命中率、目标价或当前预计跌幅。

## 10. 今日页规划

不新增顶级导航。交易结构能力进入既有“今日”和“关注”。前期只为一个主动关注标的生成用户快照；
全市场数据仅用于参照总体，不处理参照证券的公司信息或通知。

今日页按隔夜外部环境、目标关系、公司变化、内部结构、开盘反馈和数据可信度展示。前期没有多证券
排序；以下排序规则只保留为恢复多股票扩展时的兼容设计。

双轴区块由服务端使用固定排序层级：向上跨档 → 向下跨档 → 同档分数变化 → 口径切换/不可比较 →
首次基线 → 无变化。跨档层按跨档级数降序，同档变化层按 `abs(delta)` 降序；各层再按 `window_end`
降序、`instrument_id` 升序。口径切换和首次基线不读取空 delta。abstained、过期和权利缺口进入独立
“没有得到的数据”区块，不能被当作 0 分参与排序。每行包含：

1. 证券身份、数据截至时间；
2. 事件与基本面轴摘要、证据状态；
3. 交易行为轴分数、等级、模式和同模式变化；
4. 由六个诊断维度中 `ready/degraded` 项选出的最多三个显著状态变化；
5. 双轴关系及其 `system_inference` 标识；
6. 权利、过期、样本和规则缺口。

单证券压力集合接口不承担多证券首页 fan-out。R3 先实现不含压力字段的通用今日/关注聚合
读模型并登记一个公共资源；R4a 出现真实压力调用方后，复用同一摘要契约兼容增加压力、关系和服务端
排序字段。本轮不预选尚不存在的 URL，也不预建第二个行为接口。

## 11. 主动标的详情规划

移动端首屏无需横向滚动即可看到：

- 指数、等级、同模式变化；
- `盘中临时` 或 `盘后确认`；
- 一句确定性盘面摘要和六个固定维度槽；盘后“盘中接受”明确显示不适用；
- 最多三个超过版本化展示阈值的主要驱动；
- 最多两个超过阈值的有效缓解因素或反证；不足时明确写“本窗口未识别到足够缓解因素”；
- 最新事件与基本面变化；
- 隔夜外部状态、目标暴露路径、支持/反证和 09:40 后开盘反馈；
- 数据覆盖、截至时间和固定非概率说明。

下钻顺序为：五分面/十贡献簇 → 六维盘面 profile → 原始值/自身分位/正确参照总体分位 → 带系统批注的
K 线/分时 → 分模式历史 → 历史相似情景 → 公式和数据版本 → 市场数据 lineage 与授权状态。图上最多
同时显示 2–4 个与当前摘要直接相关的批注；完整指标列表只在专家下钻出现。

阈值、排序规则、`explanation_version` 与最终选中的驱动/缓解项必须随 assessment 保存；页面只展示已
物化结果，不用当前版本重新解释旧快照。

## 12. 状态和降级

| 状态 | 用户看到什么 | 系统不得做什么 |
|---|---|---|
| 尚无评估 | 尚未运行、范围未包含或尚未形成完整窗口 | 伪造 0 分或示例值 |
| 等待数据水位 | 当前窗口、等待的数据和预计下一次检查；上次有效值单独标注 | 把旧值标成当前值或提前生成快照 |
| 首次基线 | 当前有效值与“暂无同模式可比变化” | 伪造 delta 或分档变化 |
| 计算口径切换 | 新旧版本边界与“暂无可比变化”，历史图断线 | 跨版本计算 delta、连线或发提醒 |
| 样本不足 | 有效天数、最低要求和未评分 | 以同行均值填补 |
| 无有效同行 | 同板块/规则的规模近邻数量及缺失字段 | 改用行业交集或静默放宽规则 |
| 权利阻断 | 缺少 FETCH、RETAIN 或 DERIVE 中的哪项，以及旧结果能否继续展示 | 绕过授权；未经 rights policy 判断继续展示旧结果 |
| 数据过期 | 最后有效值、截至时间、过期原因 | 当作当前值 |
| 停牌 | 最后确认值和停牌说明 | 对无成交窗口生成临时值 |
| IPO 特殊期 | 规则期、历史不足和未评分 | 套用普通股票基线 |
| 规则/股本缺失 | 缺失字段和来源状态 | 用今天规则回填历史 |
| 供应商更正 | 新旧快照及替代关系 | 覆盖旧快照 |
| 事件冲突 | 并列证据，行为轴保持独立 | 自动选边或平均 |
| 相似情景处理中 | 主体分数可用，结果选择/成熟状态单独显示 | 把 pending 当作样本为零 |
| 相似样本不足/不可比 | 样本数、规则或标签缺口；主体分数继续显示 | 输出区间或抹掉主体分数 |
| 相似情景失败 | 主体分数、失败时间、稳定原因码和重试入口 | 把 analog 故障升级成主体未评分或伪造区间 |
| 退市证券 | 退市时间、最后合法确认值和审计入口 | 继续生成盘中值或并入当前同行 |
| LLM 离线 | 确定性分数、驱动和证据仍可用 | 隐藏已有确定性结果 |
| SSE 断开 | 最后更新时间和手动刷新 | 假装实时连接正常 |

所有状态文案使用“发生了什么—哪些内容仍可信—下一步是什么”的结构。

权利变化由 rights policy 决定旧结果的展示和删除：仅 FETCH 失效且原快照允许保留/派生时，可将最后
结果标为 stale 用于审计；RETAIN/DERIVE 被撤销或合同要求删除时立即停止计算，并按政策隐藏或清除受限
内容。页面不得自行推断授权后果。

## 13. 站内提醒

首版只规划站内提醒：

- 新等级连续维持两个完整 10 分钟窗口才形成分档变化；
- 同一证券、交易日和目标等级最多提醒一次；
- 升温和降温均可显示；
- 提醒只描述分档变化、主要驱动、反证和数据状态；
- 行为变化属于系统推断，不伪装成 `MarketEvent`，也不复用只面向市场事件的通知契约。

## 14. 市场产品借鉴与差异

| 参考 | 借鉴 | 明确不复制 |
|---|---|---|
| 韭圈儿、有知有行温度计 | 单一记忆点、低认知负担、历史位置 | 专有指数、权重及概率化措辞 |
| StockCharts SCTR | 同类总体中的相对排名语义 | 其技术强弱公式和美股总体 |
| TC2000/TradingView 同钟点相对成交 | 把当前成交与历史相同进度比较 | 产品名、阈值和方向化解释 |
| ChartMill | 趋势健康与位置/形态质量分开 | 专有评分、筛选规则和交易标签 |
| Simply Wall St Snowflake | 五分面摘要、逐层下钻、非买卖建议 | 专有检查项、评分和视觉资产 |
| MarketSurge | 量价信号必须结合延伸与语境解释 | “吸筹/派发”等身份化黑箱标签 |
| 同花顺、东方财富、雪球 | 指标覆盖和数据入口 | 未授权页面/付费数据及公司事实化的社交内容 |

本项目的差异化组合是：低认知负担 + 条件化量价语境 + 相对排名 + 证据链/PIT/权利失败关闭。

## 15. 产品验收

- 用户在十秒内能说出状态、变化、主要原因、反证和数据是否可信；
- 六维盘面结构状态能替代查看 MA、成交柱、分时均价线和板块宽度的第一轮人工筛选；
- 与原始图表成对测试时分别记录任务完成时间和正确率，不预先承诺改善比例；
- 同一“高换手＋大涨”在两类语境中得到不同且可追溯的解释；
- 分数为空时不显示 0，不出现静默补值或重分配权重；
- 页面不把 0–100 解释为概率，不产生交易指令；
- 确认与临时模式在文字、线型、比较和历史序列上均分离；
- 首次基线和口径版本切换不产生 delta、跨档事件或连续曲线；
- 双轴关系枚举互斥、可下钻、无需 LLM，并覆盖多事件、冲突和无变化；
- 外部市场异常不直接成为正负事件，压力分对外部输入保持不变；无目标暴露时只显示行业背景；
- 双轴关系只使用与相邻 behavior assessment 对齐的事件边际窗口；累计事件列表不得被误作同窗因果；
- explanation version、贡献阈值和已选驱动/缓解项随快照保存，历史解释可重放；
- 390px 与 360px 窄屏无页面级横向滚动，颜色不是唯一状态表达；
- 所有图形有等价文本或表格，实时更新不抢焦点；
- 无 LLM、无授权、停牌、修订和数据过期时仍能准确说明哪些内容可信。

护栏同时统计：把压力误解为概率/建议、把诊断误认为计分、把 stale/abstained 当成当前完整结果的
比例。任何一项无法被固定公式和输入重放时，不得通过体验验收。

## 16. 本轮边界

本轮只建立产品和工程规划。前期范围恰好一个主动关注标的，多股票、板块轮动和全市场压力物化延期。
以下均未实现：指数公式、行情存储、两个 planned Port、数据库迁移、计算
任务、HTTP 资源、事件、站内 SSE、双轴/量价状态卡、真实指标生产者及任何数据连接器。后续只有在
R1–R3 前置闸门通过并按 R4a → R4b → R4c 顺序实施后，才能改变这些状态。
