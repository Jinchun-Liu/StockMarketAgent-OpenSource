# 产品体验设计规范：指定股票深度研究

## 2026-08-28 R2 Web 设计基线

本节替代本文件中早于该日期的页面层级、旧 R1 页面和视觉实现建议；旧内容只保留为历史背景，不得被
活动 R2 页面导入或复用。R2 Web 从零实现“安静的研究仪器”，只复用 OpenAPI 契约和构建工具。

- `/`：合成环境标识、A 股搜索、显式候选确认和七日最近研究；
- `/research/?session=<uuid>`：真实阶段/心跳或一次性完整报告；
- `/history/`：分页历史、过期、重试与删除；
- `/auth/callback/`：Cognito Authorization Code + PKCE 回调；
- 桌面报告为十区块目录、约 760px 阅读列和右侧证据透镜；390px 使用顶部目录弹层与底部证据 sheet；
- 证据透镜展示来源、revision、PIT、支持、反证、计算和可证伪条件；模型辅助联网证据还必须显示获取方式、来源等级、交叉验证状态、可靠性系数和风险提示；
- 禁止关注、通知、目标价、Buy/Sell、持续监控和旧盘前流程入口。

视觉 token 固定为画布 `#F7F8FA`、阅读面 `#FAFAF7`、控制面 `#F5F5F7`、主文字
`#13161A`、次级文字 `#626872`、分隔线 `#D9DEE6` 和唯一交互色 `#2366D1`。不使用渐变、发光、
卡片墙或交易终端密度。IBM Plex Sans、Noto Sans SC 与 IBM Plex Mono 由锁定的 Fontsource 包自托管。
动效仅使用 140ms/220ms/360ms 三档，必须可中断；`prefers-reduced-motion` 关闭位移、缩放和脉冲。

当前主线是 R2：**搜索一只 A 股 → 明确确认规范证券 → 创建独立研究会话 → 全球事件按需匹配 →

## R2 页面与交互

报告 1.2 默认打开“易读版”。授权事实模式下，模型仅按统一五档证据 rubric 判断六个维度并选择该维
允许的证据，程序再确定性复算维度分、可靠性调整、加权总分和分档；缺少任一维度的合格证据时必须
弃权并显示“暂不评分”，不能用中间档代替未知。`50` 只表示当前证据下优劣大致平衡，不表示推荐概率。
合成 v4 场景调用同一评分模型，仅使用同一快照内有效合成事实。评分卡以 scoring_basis=synthetic_scenario 区分真实证据模式；档位乘以 25，计算系数为 1，调整分等于原始分。真实来源核验显示“不适用（合成）”，evidence_confidence 保持 0；计算系数不是来源可信度。六维齐全才给总分，缺维保留未评分和原因；模拟分不进入真实公司排名。商业、财务、竞争、管理层、估值、风险韧性权重分别为 20%、20%、15%、10%、15%、20%，风险分越高表示韧性越好。旧 v3 缺证案例保留。

易读版是同一份已验证报告的确定性呈现，按“核心结论—关键事实—看多分析（Bull）—看空分析（Bear）—
综合判断—风险与待验证—来源与方法”展开。保留专业章节的完整实质正文、全部论点、成立条件、不确定性、
反证、计算口径与引用；不把报告压缩成摘要卡片。正文使用约 760px 阅读列、17px 中文、1.75 行高，长标题
自然换行。桌面有固定目录，窄屏目录按顺序排列；表格独立横向滚动，不撑宽整页。

“易读版 / 专业十区块 / 方法与来源”只切换本地展示，不请求模型重写。评分细节、六维说明和公开分析步骤
在结论附近展示总分、六维分与主要问题，方法页和专业版可查看详细理由、支持与反证。文档标题为“研究报告 · 合成模拟”，研究质量独立显示。正文中的“查看依据”只打开同一报告实际存在的 claim 或来源记录，其他
Markdown 链接不激活。评分的文档引用直接打开来源元数据与同源事实，不把同一来源的第一条或最后一条
事实当成该维度的唯一依据；逐条论点引用仍打开对应 claim。原始 HTML、图片和嵌入内容仍不可执行。关闭证据透镜后恢复触发元素焦点及阅读位置。
打印与 Markdown 下载使用同一报告内容。

正文之后展示全部证据缺口的中文说明与次级原因编号，并列出全部 claims 的证据入口，不依赖模型选择子集。
旧报告通过既有只读投影读取，不改写原件。历史入口使用“打开研究结果”；未完成且有已验证内容时使用
“查看可用结果”，不得标为完整报告。

方法菜单默认自动选择。手动模式固定保留核心方法，最多追加六个可用方法；组合与非上市公司方法展示为
“不适用于当前 A 股单股研究”，不可绕过。运行目录由 20 个适配分析方法与投资备忘录写作层组成；模型
只接收项目强类型模板。服务器拒绝纯英文或拉丁文本占主导的用户叙述，首次失败只允许一次结构修复，
仍不合格时从已验证事实和中文固定模板安全编译。服务器从已验证章节与论点编译 Markdown，前端只呈现报告中保存的版本。

`/research` 是单一任务入口。用户可输入六位代码、带交易所代码、公司简称或全称；候选列表同时显示
规范代码、交易所、上市状态和匹配类型。无论精确还是模糊命中，创建前都要由用户确认；歧义结果不
自动选择，非 A 股和无结果给出稳定说明。

搜索页明确说明目录是离线开发快照，覆盖沪深北当前 A 股与沪深历史退市身份。公司全称只有在目录来源
提供并完成字段核验时显示；只有证券简称的深交所/北交所候选显示“公司全称将在研究阶段核验”，不得
重复简称制造已核验全称的错觉。历史换码证券用旧代码或旧名称搜索时必须指向当前规范身份，不得重复
显示为另一个退市公司。静态目录不推测动态停复牌状态；目录超过保留截止时间时显示服务暂不可用，而不
继续展示缓存结果。

确认后页面轮询 `ResearchSession`，按 `queued / collecting / analysing / validating / publishing`
等真实阶段显示最后进展时间、覆盖窗口和缺口，不显示猜测百分比。停滞时显示等待恢复，仅在服务器
声明 retryable 时提供“恢复研究”；运行中可取消。Session 1.0 / 1.1 均可读取，1.1 明确区分完整、部分完成、
证据不足与执行失败。未完成会话可显示服务端保存的已验证结果，持续标注未完成与合成属性，不展示模型未验证半成品。

已验证内容可编排为以下十个固定区块，缺失内容明确说明问题：标的与覆盖、业务模式、财务趋势、历史估值、重大
事件/国际事件与宏观暴露、Bull、Bear、冲突与未知项、可证伪条件、逐条证据与版本。国际事件区直接
展示事件时间/revision、暴露直接度、影响渠道、方向、支持、反证、来源和覆盖缺口；主张显式区分事实、系统
推断和模型假设；证据可下钻。失败时显示稳定原因与恢复资格，并保留可用的已验证内容；部分结果也提供七段易读版、十个专业区块及导出，但研究质量仍为部分完成，不计入完整成功率。有可读文档时执行进度默认折叠，保留展开、真实原因和恢复入口。

历史列表只显示仍在七日保留期内的会话。提前删除立即终止访问；重复删除保持幂等。界面持续显示
“合成测试数据/非生产数据”，不提供 watchlist、持续关注、未来监测、通知、目标价、Buy/Sell 或收益承诺。

响应式和无障碍基线：390px 无横向滚动，表单有可见标签和错误关联，键盘可完成搜索、确认、取消、
重试、查看与删除；状态不只依赖颜色；焦点可见；动态状态使用 `aria-live="polite"`；触控目标至少 44px；
遵循 `prefers-reduced-motion`。

## R1 兼容体验

## 1. 用户、场景与页面唯一任务

目标用户是第一次接触市场数据，或不愿自行分析复杂表格的研究用户。系统持续处理固定主动标的及其
宏观环境，但前期不要求用户管理复杂组合。盘前时间短、信息密度高，用户首先要知道的是：

> 五类信息各出现了多少条变化、数据是否完整；需要核验时，去哪里查看来源、日志、方法和证据？

首页是高度简化的可视化概览。仪表外观借用气压表的直观读数，但只表达变化条目数量，不表达涨跌
概率、风险分、预计收益或交易建议。任何仪表、文字或动效都必须服务于快速识别变化和数据缺口，
不能用涨跌颜色或模糊 AI 结论替代证据。

## 2. 信息架构

主导航只保留两个入口：

1. **概览**（`/`）：用五个简化仪表展示五类返回条目数量，面向只想快速理解结果的用户；
2. **详情**（`/details/`）：展示来源状态、五类数据与变化、脱敏审计日志，以及数据计算的理论依据和
   方法说明。

证据页（`/evidence/{event_id}/`）是从详情页变化条目进入的深链，不占用主导航。设置、事件全集、
对话、研究等能力只有在真实运行路径与验收存在后才能新增入口；不得为规划能力在首版放置空导航。
板块轮动和多股票组合保留为后续扩展。

### 2.1 R1 固定目标只读状态

概览和详情页均只读呈现固定目标兆易创新（`XSHG:603986` / `603986.SH`）、revision 1、数据截止时间
和来源覆盖状态。首次启动由系统初始化固定目标；重复启动是幂等 no-op。

R1 页面不得出现证券搜索框、代码输入框、添加/激活/删除/切换按钮或任何暗示可以变更标的的控件。
如果配置或内部调用携带其他证券，页面只显示稳定的 `R1_TARGET_LOCKED` 故障状态，且不得触发外部
来源访问。用户输入、激活和切换属于 R1 后续兼容扩展。

## 3. 两页蓝图

### 3.1 极简概览页

首屏按以下稳定顺序组成：

1. 紧凑页头：产品名、固定标的、数据截止时间、整体来源状态和两个主导航入口；
2. 五个仪表：法定公告、财务变化、行情快照、公司与行业新闻、相关宏观快讯；
3. 数据完整性说明和进入详情页的明确动作；
4. 固定研究用途说明。

五个仪表遵循同一数据与视觉契约：

- 每个仪表的原始值严格等于对应分类返回数组的 `items.length`，只显示非负整数，不做权重、平均、
  归一化、风险换算或前端推导；
- 五个仪表共用 `0–10+` 刻度。`0` 到 `9` 按实际整数定位，`10` 及以上的指针停在 `10+` 端点，
  中央数字仍显示真实整数；
- 分类缺失、不可解析或未返回时显示 `—`，不显示指针，也不得把缺失换算成 `0`；真实空数组才显示
  `0`，并配合数据完整性文字区分“无变化”和“未取到”；
- 仪表标题位于下方；右上角提供带可访问名称的问号。鼠标悬停、键盘聚焦或触控激活时，显示该分类
  的定义、数据范围、当前值含义和限制；
- 刻度可使用从低到高的离散色阶，但每一档必须是纯色段，且同时提供数字、刻线和文字，颜色不能成为
  唯一含义；
- 指针在初次呈现或数值变化时平滑移动，并可有有限时长的轻微抖动；值越接近 `10+`，抖动频率越高，
  但振幅保持克制，不持续无限播放，不影响读数；
- `prefers-reduced-motion: reduce` 下取消扫针、位移和抖动，只呈现最终状态。缺失值同样不得播放指针
  动画。

首页只有一个主动标的，不做多证券分数排序。仪表只回答“这一类有多少条变化”，不回答变化方向、
重要性、风险、概率或建议。没有变化时显示整数 `0`，并同时显示覆盖范围和最后成功时间；来源缺权、
过期或失败时必须明确显示缺口，不能用 `0` 或空白暗示系统已检查全部来源。

首屏固定显示：

> 本页仪表仅汇总变化条目数量；外部环境和交易结构不代表涨跌概率、预计跌幅或交易建议。
>
> 本项目仅供研究和纸面验证（research-only / paper-only），不提供真实下单或自动交易能力。

### 3.2 详情页

详情页按以下稳定顺序提供可核验信息：

1. **来源状态**：两个独立合成来源角色的状态、最后成功时间、业务 watermark、批次审计 ID
   和“已推进/未推进”；
2. **五类数据与变化**：按与概览页相同的五类顺序列出 `NEW`、`UPDATE`、`CORRECTION`、
   `CONTRADICTION` 或 `no_change`；
3. **脱敏审计日志**：仅展示允许公开的时间、阶段、稳定状态/原因码和审计标识，不展示 provider
   cursor、密钥、授权原文、内部堆栈、私有持仓或未脱敏原文；
4. **理论依据与计算方法**：说明计数口径、变化/revision 语义、来源完整性、PIT（point-in-time）、证据
   链，以及事实、系统推断和概率研究为何分区呈现。

每个变化条目必须包含股票简称与规范代码、文本状态标签、只陈述证据事实的摘要、发布时间、首次发现
时间、当前延迟、来源名称与权威度，以及指向 `evidence_id` 的“查看证据”动作。如有系统推断，单独
标记依据、不确定性和“系统推断”；如有纸面预测，单独显示模型、`as_of`、区间与 `paper_only`。
不允许把事实、推断和预测合并成一句结论。

provider cursor 是仅供 adapter 内部使用的不透明秘密，不得进入页面、HTTP 响应、审计展示或无障碍
名称/描述。事实区不能等待 LLM；生成能力不可用时仍保留确定性事实、revision、来源缺口和证据深链。

### 3.3 两页之间的一致性

- 概览仪表与详情分类必须来自同一份已校验响应，不允许前端另算分类或补写条目；
- 详情中每类可见条目数必须与概览的对应整数一致；若响应不完整，两页均显示同一缺失状态；
- `no_change`、来源失败、rights blocked、stale 和 partial 是不同状态，不得互相替代；
- 概览到详情不超过一次激活，详情变化到证据页不超过一次激活；
- 10 秒人工可理解性测试从稳定内容 ready 时刻开始：加载态结束、主要 landmarks 已渲染且不会自动
  重排；网络与加载耗时另行记录，不混入理解计时。

#### DEV_ONLY 全失败体验回退

当且仅当当前运行的五类能力全部为 `gap`、`blocked` 或 `failed`，且构建中存在已通过契约校验的完整
历史演示快照时，公开预览可以把“五类结果区”整体切换到该历史快照，以便验证仪表、明细和证据交互。
该模式必须同时满足：

- 当前运行的 `data_as_of`、来源失败状态、原因码和审计 ID 继续单独展示，不得被历史状态覆盖；
- 五类结果只能整体来自同一份历史 briefing，禁止按类别混合当前与历史，也禁止把缺失补成合成事实；
- 概览与详情显著显示 `DEV_ONLY`、历史数据截止时间、“不代表当前市场”和“不代表真实来源成功”；
- 历史空数组继续显示真实整数 `0`，有条目时保留历史证据深链；当前来源恢复任一可用类别后立即退出该模式。

这是一项功能体验降级，不改变来源授权、质量等级、PIT 语义或正式数据就绪状态。

## 4. 证据下钻与修订

证据下钻使用可直接访问的 `/evidence/{event_id}/` 深链。宽屏可以呈现为右侧阅读面板或独立阅读页，
窄屏使用全屏阅读页；直接打开深链必须可用，从详情进入后应提供清晰返回动作并尽量恢复原条目位置。
证据视图从上到下为：

1. 事件标题、状态、证券和事件时间；
2. revision 时间线，当前版本高亮；
3. 事实槽位差异：旧值、现值、单位、期间；
4. 原始来源元数据：标题、来源、发布时间、首次发现、hash、rights snapshot；
5. 原文位置或许可允许的原文片段；
6. 系统抽取版本、规则版本和可审计 ID。

`CORRECTION` 使用“原值被更正为现值”的方向性 diff；`CONTRADICTION` 并列展示两个 evidence
claim/revision 和各自证据，不要求二者来自不同来源。同一 `source_id` 的两个仍有效冲突 claim 也必须
并列；只有来源明确声明 replacement/retraction 时才展示为方向性 `CORRECTION`。界面不自动选边，
不用平均值掩盖冲突。只有元数据可保留时，显示证据存在及许可限制，不能展示未授权原文。

## 5. 质量与推断维度必须分开

| 信息 | 回答的问题 | 展示方式 | 禁止行为 |
|---|---|---|---|
| 来源权威度 | 来源在事实链中的地位如何 | 离散等级与来源类型 | 与模型概率相乘成总分 |
| 抽取置信度 | 系统是否正确抽取事实槽位 | 0–100% + 抽取版本 | 作为事实真伪概率 |
| 暴露直接度 | 事件与公司经营关系有多直接 | 官方点名/公司披露/一跳证据/行业背景 | 用新闻共现或模型常识升级关系 |
| 推断不确定性 | 影响解释有哪些未知条件 | 低/中/高 + 条件文本 | 写成无条件利好/利空 |
| 预测概率 | 冻结模型对纸面结果的概率 | 概率、区间、as-of、paper-only | 未校准时展示；暗示收益承诺 |

来源权威度不能越过权利检查；高权威但无授权的来源仍不得获取或缓存。低分社交内容只显示聚合情绪和样本范围，不形成公司事实卡片。

## 6. 视觉语言

### 6.1 设计概念

视觉概念为“精简气压表与证据纸页”：概览页用少量留白充足的仪表快速回答数量问题，详情与证据页
延续公告纸张的边注、交易时间戳和修订痕迹。整体应安静、克制、易读，不模仿高密度金融大屏。

概览页的标志性元素是简化仪表；详情页的标志性元素是贯穿变化与证据面板的**证据脊线**。每个时间点
连接 source、first seen、revision 和 briefing，用户能沿线理解“何时发布、何时看见、何时被更正”。

### 6.2 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `paper` | `#F2EDE2` | 主内容底色，减少长文阅读疲劳 |
| `ink` | `#18201D` | 正文与主导航 |
| `registry` | `#174A43` | 证据脊线、链接、确定状态 |
| `stamp` | `#B64A35` | 更正、阻断、需要处理 |
| `brass` | `#9A7628` | 延迟、待核验、不确定 |
| `fog` | `#D8D4C9` | 边界、禁用和历史层级 |

页面主题、背景、按钮、卡片和装饰不得使用渐变；所有主题面均使用上表纯色。仪表刻度可以按固定阈值
使用多段离散纯色，但不得用 CSS/SVG 渐变补间，也不得把色阶解释为涨跌或利好利空。状态同时使用
文字、图标和形状。深色模式可在 R3 后增补，但首版以适合快速扫读和长文本证据阅读的浅色主题为主。

### 6.3 字体与密度

- 正文和交互使用清晰的中文无衬线字体栈；
- 公告标题和原文引句可使用中文宋体栈，强调文书来源；
- 代码、时间、hash 和 evidence ID 使用等宽字体；
- 不在整个页面使用等宽字体，不用全大写作为普通导航；
- 桌面单栏正文目标 68–82 个中文字符，数据表可横向扩展；默认高密度但保留 44px 的触控目标。

## 7. 状态设计

| 状态 | 必须回答 | 推荐动作 |
|---|---|---|
| Loading | 正在处理哪一步、从何时开始 | 允许查看上次成功简报 |
| Empty | 是真实零条变化、固定标的尚未初始化还是尚未运行 | 查看覆盖范围或详情 |
| Stale | 数据截至何时、超过哪个目标 | 查看来源健康、手动重试 |
| Partial | 哪些来源成功、哪些缺失 | 继续阅读已证实部分 |
| Rights blocked | 缺什么授权或用途 | 打开来源权利说明 |
| Unavailable | 哪个依赖失败、最后成功时间 | 使用上次结果，不补写事实 |
| Conflict | 哪些事实互相矛盾 | 并列查看证据 |
| LLM offline | 生成不可用但证据是否完整 | 查看确定性证据列表 |
| Forecast locked | 未达到哪个数据/质量闸门 | 查看研究方法与当前状态 |

所有错误使用用户可理解的“发生了什么—哪些内容仍可信—下一步是什么”结构。内部堆栈、密钥、原始授权文本和私有持仓信息不能进入错误详情。

R1 的来源状态进一步冻结为：

| 触发 | 必须显示 | 唯一动作 | 禁止行为 |
|---|---|---|---|
| 未授权或 403 | `SOURCE_UNAUTHORIZED` 或 `SOURCE_FORBIDDEN`、最后成功时间、业务 watermark、批次审计 ID 与“未推进” | 查看来源权利说明 | 展示原始 cursor；自动改用交易所网页、聚合器或缓存 |
| 429 | `SOURCE_RATE_LIMITED`、本批次未提交、可安全披露的重试时间 | 查看来源状态 | 无限重试、换身份或换 IP |
| timeout/5xx | `SOURCE_UNAVAILABLE`、有界重试已耗尽、最后成功时间 | 手动重试或查看上次结果 | 用 LLM 或旧值补写当前事实 |
| synthetic only | “仅合成演示，不代表真实来源成功” | 查看覆盖说明 | 把 synthetic 内容标成法定公告 |
| LLM 离线 | “生成不可用；确定性证据仍可核验” | 查看证据 | 隐藏事实、revision 或来源缺口 |

## 8. 响应式与无障碍

- 关键断点以内容是否可读为准，不以特定设备型号为准；
- 五个仪表在宽屏保持平衡网格，在窄屏按稳定顺序转为单列或双列；不得为了凑满一行压缩读数、标题或
  44px 交互目标；
- 360px 宽度下仪表、问号解释、变化标签、来源状态和证据动作无需横向滚动；事实、推断、概率三个区
  按同一顺序纵向排列；
- 窄屏把证据视图切换为全屏，返回后恢复列表焦点和滚动位置；
- 两项主导航在窄屏仍直接可见；概览与详情互相一键可达，不隐藏到多层菜单；
- 问号解释同时支持 hover、focus、触控和 Escape/点击外部关闭，打开后不抢走后续键盘顺序；
- 所有动作有可见焦点，事件条目本身不是唯一点击目标；
- 时间线、diff 和图表提供等价文本/表格；
- 颜色对比满足 WCAG AA，支持 200% 缩放和 `prefers-reduced-motion`；减少动效时仪表不扫针、不抖动；
- 实时更新不抢焦点，使用可控的 polite live region；
- 键盘可完成筛选、打开证据、切换 revision、关闭面板和回到触发点。

## 9. 文案规则

- 事实用“公告显示/政策文件载明”；推断用“系统推断/可能”；预测用“纸面模型估计”；
- 不使用“必涨、稳赚、建议买入/卖出、准确率更高”等承诺；
- `confidence` 必须带限定名，不单独显示“置信度”；
- 仪表说明必须使用“变化条目数量”，不得写成“风险”“热度”“机会”“压力”或“概率”；
- 延迟、无授权和部分覆盖直接说清，不用“暂无数据”混淆原因；
- 时间默认展示 `Asia/Shanghai`，同时保留可查看的 UTC 审计值。

## 10. 体验验收

自动化 E2E 冻结为确定性结构与交互检查：

- 稳定且命名的 `main`、两个主导航、五个仪表、主动标的、来源状态、审计、方法、事实、推断、概率和
  证据 landmarks 均可由 role/name 定位；
- 以 `0`、`9`、`10`、大于 `10`、真实空数组和缺失分类覆盖共同刻度、真实整数、`10+` 指针钳位及
  `0`/`—` 区分；详情对应分类条目数与概览一致；
- 每个问号可由鼠标、键盘和触控打开，解释包含分类定义与限制，焦点可见且可关闭；
- 指针能到达最终值，高值抖动频率高于低值但动画有限时长；reduced-motion 下没有扫针、位移或抖动；
- 状态有可读文本与可访问名称，不依赖颜色；从概览到详情、再从变化到目标 `evidence_id`/revision
  各不超过一次激活，从证据视图返回后焦点和滚动位置回到原条目；
- 详情页同时覆盖正常、partial、rights blocked、stale、unavailable 和 synthetic 状态；审计区只出现
  允许公开字段，方法区明确 `items.length`、PIT、revision 与 evidence 口径；
- 360px viewport 的核心路径 `scrollWidth <= clientWidth`，键盘、屏幕阅读器和 reduced-motion 路径
  可完成首次激活、重复激活、切换与证据下钻；实时更新不抢焦点；
- 静态样式检查确认主题面不含渐变；仪表刻度如有多色，只由离散纯色段组成；
- 将唯一 sentinel token 注入假 provider cursor，断言 HTTP body/header、可见 UI、accessibility tree、
  log、metric label/exemplar、error 和 trace 均不包含该 token。

人工可理解性测试与自动化分开：计时起点是稳定内容 ready（加载态结束且上述 landmarks 已渲染），
首次用户须在 10 秒内准确指出主动标的、五类变化数量、数据缺口和数据截止时间；随后能在详情页指出
来源状态、最近变化、脱敏审计、方法入口和证据深链。记录用时、答案准确性和独立加载耗时。
任何页面均不得把系统推断或概率预测伪装成来源事实。

页面显示 `as_of`、输入覆盖、公式/规则版本、状态解释、反证和缺口，不提供实时仪表盘、十分钟刷新、
档位提醒、09:40 反馈、通知或 SSE。快照缺核心输入时显示 abstain，不回退到旧值或由模型补全。

### 11.1 两页中的双轴信息

概览页只把行为与盘面相关返回条目计入“行情快照”等对应分类的 `items.length`，不把压力指数本身
改造成第六个仪表，也不根据分数改变仪表颜色含义。详情页按以下稳定结构呈现主动关注标的：

1. 证券简称、规范代码、数据截至时间；
2. 事件与基本面轴：最新实质变化、revision 类型、证据入口和缺口；
3. 交易行为轴：交易结构压力指数、等级、同模式变化、盘中临时/盘后确认和覆盖；
4. 最多三个显著盘面状态变化，来自固定六维而不是自由生成标签；
5. 单独的双轴关系：使用产品规格定义的互斥 `AxisRelationship`，并提供依据下钻；
6. 授权、过期、样本、股本和交易规则缺口。

前期恰好一个主动标的，因此不做证券间排序或逐证券 fan-out。长期多股票扩展若恢复，仍只能复用服务端
稳定排序，不能由前端按绝对最高分重排。口径切换和首次基线不使用空 delta。

单行主状态由服务端按 `LAST_CONFIRMED → INTRADAY_EXPECTED/INTRADAY_ACTIVE → POST_CLOSE_PENDING →
CURRENT_CONFIRMED` 状态机选择。开盘前及首个完整窗口结束前显示最近确认值并标明交易日；窗口应到但
尚无 assessment 时显示等待/延迟，不把旧确认值伪装为当前值；盘中显示最新当日临时值；收盘等待期间
保留最后临时值并标明等待确认；当日确认值到达后替换主状态。当前阶段的 degraded/abstained 必须原样
显示，不能回退到旧 ready 值。前端刷新和 SSE 更新复用同一服务端选择结果，模式切换不生成跨模式变化。

累计事件列表从上一成功简报游标开始；双轴关系只使用与当前/上一可比 behavior assessment 对齐的事件
边际窗口。页面同时标注两个窗口，并说明“同窗变化不代表事件导致了价格行为”。

### 11.2 详情页中的主动标的下钻

当该能力真实接入后，详情页对应区域在 390px 和 360px 窄屏无需横向滚动即可看到：

- 交易结构压力、等级、同模式变化；
- “盘中临时”或“盘后确认”文字标签；
- 一句确定性盘面摘要；
- 趋势组织、位置与修复、成交参与、波动环境、盘中接受、相对环境六个固定维度槽；不可用槽显示状态
  原因而不是伪造业务状态；
- 最多三个超过展示阈值的主要驱动；
- 最多两个超过阈值的有效缓解因素或反证；不足时显示“本窗口未识别到足够缓解因素”；
- 最新事件与基本面变化；
- 隔夜外部状态、最多三个异常、两个反证、目标暴露路径和 `PROVISIONAL/CONFIRMED` 数据状态；
- 09:40 后开盘反馈；未到窗口、停牌或行情不足时显示 `NOT_YET_CLASSIFIABLE`；
- 数据覆盖、更新时间和固定说明“不是下跌概率或买卖建议”。

候选公式晋级后的下钻顺序才可采用五分面/十贡献簇、六维盘面状态、原始值/自身历史分位/正确参照总体分位、带系统批注的
K 线与分时、分模式历史、历史相似情景表格、公式/规则/同行/manifest 版本、证据和授权状态。确认与
临时历史分区展示，不连线、不跨模式显示变化值。

### 11.3 视觉与语义

- 概览页五个仪表只表示变化条数，不承载交易结构压力总分；
- 详情中的压力总分使用数字、等级和文字说明，不以仪表或颜色作为唯一解释；
- 详情中只允许一个数值总分；六维状态不得被再次平均成“技术分”或显示 Buy/Sell；
- `CONFIRMED` 使用实线及“盘后确认”，`PROVISIONAL` 使用虚线及“盘中临时”；
- `ABSTAINED` 显示“未评分”与原因，不能显示为 0；
- 影子候选五分面使用紧凑条形并提供等价表格，不以雷达图增加比较负担，且必须标记“未晋级”；
- K 线/分时唯一使用 Lightweight Charts，只渲染后端已计算的数据；同屏最多 2–4 个与摘要直接相关的
  批注。宽度、分布等非金融通用图才使用 ECharts；
- 默认不展示 RSI/MACD/KDJ 指标窗格；专家下钻也不能让前端生成第二套计算结果；
- 分数为高不使用“必跌”“危险卖出”等措辞；状态颜色继续配合文字、边框和图形；
- 固定非概率说明中可以出现“概率”一词；禁止的是“数字百分比 + 下跌概率”式预测表达。
- `post_close` 固定映射为 `CONFIRMED`，`intraday_10m` 固定映射为 `PROVISIONAL`；页面不得接收或
  展示其他组合。
- `comparison_semantics_hash` 变化时历史线断开，并显示“计算口径已更新，暂无可比变化”。

### 11.4 行为轴状态矩阵

| 状态 | 必须显示 | 禁止行为 |
|---|---|---|
| No assessment | 尚未运行、范围未包含或尚无完整窗口 | 伪造 0 分/示例值 |
| Waiting for watermark | 当前窗口、等待项、上次有效值及其截至时间 | 把旧值当当前值 |
| First baseline | 当前值和“暂无同模式可比变化” | 伪造 delta/transition |
| Formula boundary | 新旧口径版本、断线和基线重置 | 跨版本连线、比较或提醒 |
| Confirmed | 交易日、数据水位完成时间 | 与盘中值连线 |
| Provisional | 完整 10 分钟窗口、虚线语义 | 伪装成收盘值 |
| Insufficient history | 有效天数与最低要求 | 用行业均值补齐 |
| No peers | 同板块/规则的规模近邻数与缺失字段 | 临时改成行业交集或静默放宽规则 |
| Rights blocked | 缺少 FETCH/RETAIN/DERIVE 中哪项 | 未授权抓取或缓存 |
| Stale/degraded | 最后有效结果、截至时间、原因 | 当作当前完整状态 |
| Halted | 停牌说明和最后确认值 | 对无成交窗口算临时值 |
| IPO rule period | 特殊规则期与样本缺口 | 套用普通基线 |
| Missing rule/capital | 缺失规则或股本 | 用今天规则回填历史 |
| Supplier correction | 新旧快照和替代关系 | 覆盖旧快照 |
| Event conflict | 并列证据，行为轴独立 | 自动选边或平均 |
| External insufficient | 缺失核心市场、历史样本或授权 | 用可用块重分权重或生成平稳状态 |
| Stale overseas market | 休市原因、上一有效会话和过期标签 | 把前值构造成零变化 |
| Unpriced event | 事件时间、尚未交易的相关市场 | 声称市场已确认影响 |
| Mixed repricing | 显著块、方向冲突、支持和反证 | 合成单一外部分数 |
| Exposure background only | 行业背景和缺失的公司证据 | 生成公司利好/利空结论 |
| Analog pending | 主体分数与情景选择/结果成熟状态 | 把 pending 当零样本 |
| Analog insufficient/incomparable | 样本数、规则或标签缺口 | 输出结果区间或隐藏主体分数 |
| Analog failed | 主体分数、失败时间、稳定原因码和重试入口 | 把情景模块故障当主体未评分 |
| Delisted | 退市时间、最后合法确认值和审计入口 | 继续生成临时值或纳入当前同行 |
| LLM offline | 确定性分数、驱动和证据 | 隐藏已有结果 |
| SSE disconnected | 最后更新时间和刷新入口 | 假装实时在线 |

盘面结构 profile 始终存在，每个维度有独立 `ready/degraded/abstained/not_applicable`。只有前两者显示
业务状态；后两者的 state 为空并显示稳定原因。例如 `post_close` 或开盘前的盘中接受为
`not_applicable`，不能沿用昨日“VWAP 上方接受”；压力未评分时，有完整输入的趋势组织仍可显示，但必须
明确它没有补齐压力分。

旧结果是否仍可展示由 rights policy 决定：原授权允许保留且无删除义务时只能作为明确过期的审计值；
RETAIN/DERIVE 被撤销或合同要求删除时，页面按服务端决定隐藏或移除，不能自行回退到缓存。

### 11.5 无障碍与实时更新

- 页面有跳到主要内容入口、唯一主标题、语义化区域和可见焦点；
- 分数的无障碍名称完整表达指数名、模式、等级和数据状态；
- 时间使用 `<time>`，默认上海时区并可查看 UTC 审计值；
- 站内分档变化使用 `aria-live="polite"`，不抢焦点、不改变滚动位置；
- 证据视图关闭或返回后恢复触发元素焦点；
- 支持键盘、200% 缩放、`prefers-reduced-motion` 和强制颜色模式；
- 所有交互目标至少 44px。

### 11.6 当前实现状态

### 11.7 “更直观”的验证

实施后用同一组证券与同一截止时间做成对任务：一组只看原始 K 线/分时/MA/成交柱，一组看本产品状态
卡并可下钻。记录任务正确率、完成时间、十秒复述率和两次操作内找到原始输入的比例；同时记录压力被
误解为概率、诊断被误解为计分、过期/未评分被误解为当前完整结果的比例。未测量前不写“效率提升
X%”或“判断更准确”。
