# R2 易读研究、方法库与联网发现复用决定

## 决定

- 固定 `xbtlin/ai-berkshire@fd83d06347c6e3ee50133cda6962f40e226b5252` 作为方法来源参考，保留 MIT 许可证、21 份上游 Skill 原文、投资备忘录写作层和逐文件哈希。运行目录采用其中 20 个分析方法与投资备忘录写作层组成 21 项；`wechat-article` 只保留来源记录，避免与写作层重复。
- 上游原文不进入运行时提示。运行时只读取项目拥有的强类型适配模板，删除单股研究边界外的行动、配置、未来价格和权威背书语义。
- 复用现有 `LLMProviderPort` 和单一 `deepseek-v4-pro` 路由；模型只做问题拆解、按统一 rubric 判断证据等级和简体中文改写，确定性程序负责身份、PIT、单位、来源独立性、证据允许集合、评分复算与发布资格。不为短解释增加 Flash 路由或第四次模型调用。
- 新增供应商无关 `SourceDiscoveryPort`，Tavily 仅实现候选 URL 发现。项目继续复用 `SourceConnectorPort` 完成受控页面获取；同一 adapter 兼容旧单 key Secret 和有序 `api_keys` 池，不增加第二个 Port 或密钥协调服务。
- Web 采用 `react-markdown@10.1.0` 和 `remark-gfm@4.0.1` 展示服务器编译的安全 Markdown，不引入第二套文档编辑器或原始 HTML 渲染器。

## 自建缺口

- 上游方法缺少强类型契约、PIT、来源独立性、禁用边界和评分校验，必须由项目适配层补齐。评分不是纯确定性判断：模型仅按证据 rubric 选择档位，程序确定性计算并验证结果；任一维证据不足即弃权。
- Tavily 不提供项目权利、SSRF、robots、历史版本和事实资格判断，必须由现有来源边界与项目规则补齐。当前研究只遍历一次查询已经返回的最多五个候选，且 URL hostname、候选 domain 与登记来源必须完全一致；历史研究没有网页观测库，因此禁止调用实时 Tavily。项目 adapter 对 key 池先去重并限制最多 10 个唯一项；一次发现共享 15 秒期限，只为 401/403 认证失败、429 请求速率限制或 432 套餐用量上限顺序换 key，429/432 统一归类为 `TAVILY_QUOTA_EXHAUSTED`，且不持久化游标或跨请求重排。
- 页面抓取结果继续标记为 `INELIGIBLE`；项目自建的摘录绑定器必须在已抓取正文中精确找到连续摘录，并确认数值和单位位于摘录内，否则只保留失败回执。
- 历史页面的真实首次观测时间不能被模型或 adapter 回填。显式 `as_of` 是历史研究的固定截点，只保留 `WEB_PIT_NOT_ELIGIBLE` 缺口；未传 `as_of` 是当前研究，页面发布日期和已知修订时间不得晚于会话创建时间，而合格 citation 的真实 `first_seen_at` 可将最终报告截点向前推进到任务期限内。
- 普通读者版必须与专业报告使用同一完整主张和证据 ID，因此 Markdown 必须由服务器从结构化字段编译，而不是直接展示模型原文。现有 `reader_overlay` 直接参与 Reader 提示；提示固定要求简体中文，封闭数值表达式只拦截实际数量语义，不以中文数字字符白名单误伤公司名。内容必须明确 `business.core_products`、`business.customer_revenue_chain`、`business.product_structure_change`，证据不足时写明规范原因码和中文缺口。
- 合成 v4 场景复用现有评分模型和六维 rubric，以 synthetic_scenario 显式标记；仅允许同一快照的有效合成事实，计算系数 1、真实来源可信度 0。真实证据模式保留原可靠性计算。v3 缺证案例不改写，缺维不补分、不重分配权重；历史报告不重新评分，读取投影保留新版本已保存模拟分，原数据库与 S3 制品不重写。

## 供应链和权利

- ai-berkshire 按固定提交 vendoring，不执行仓库脚本，不作为 Codex Skill 安装。
- Tavily 和 DeepSeek 密钥只由 worker 的 Secrets Manager 注入；查询正文、网页正文、模型输出和 key 值不得进入日志。Tavily Secret 切换 `AWSCURRENT` 后通过 ECS worker 重启生效；回滚旧镜像前先恢复与其兼容的旧 Secret `AWSCURRENT`，全程只核对版本元数据。
- 网页来源处于 `DEV_ONLY/UNVERIFIED`，只允许私有 R2 合成/混合预览；生产门禁保持阻断。

## 2026-09-05 完整研究支持核对与恢复修订

- 继续复用 `LLMProviderPort`、既有研究 Repository、Pydantic 与安全 Markdown 编译器；不引入框架、依赖或新的执行引擎。研究调用从“叙事 + 易读改写”调整为“叙事 + 独立支持核对”；合成和真实证据均复用既有评分步骤，核心支持不足时仍尽量完成评分与文档并诚实保留 partial 质量。阶段 snapshot 记录逻辑 provider 请求数量，不把它冒充供应商 HTTP 重试次数或实际计费回执。
- 删除全局六条事实/来源、必须存在数值、恰好一条 Bull/Bear、provider 输出十标题、独立 provider/source group 和恒等推断硬门；现有十章节仅作为外部 1.1 兼容容器。完整结果必须保有经过支持核对的看多、看空和综合判断；未完成或无支持的内容不计完整成功，保留可核验事实与已完成部分。
- 每项假设的 `fact_key + evidence_id + excerpt` 必须绑定输入事实及连续原文，再用现有 provider 独立判断摘要、论点前提、支持方向与反证相关性。ID 存在、同源或来源数量均不能替代支持关系。模型核对具有不确定性，不是逻辑证明；合成 provider 只对固定合成事实生成的已知论点作可拒绝的回放核验，不代表真实模型能力。
- 数值原文与事实完整保留；现有模型叙事数值边界保持，提示明确不在论证复写数值，避免引导模型输出随后必被删改的内容。标题由系统组织，标题措辞不构成报告质量硬门。
- 易读版从全部已验证摘要、主张、条件、反证、系统计算与引用确定性编译，按“核心结论—关键事实—看多—看空—综合判断—风险与待验证—来源与方法”组织。不存在独立易读模型调用，视图切换不重新生成文本；旧报告兼容读取保留。
- 保存初始事实、支持核对完成后的叙事、评分卡和最终报告；评分按输入与生成器版本恢复，不重复已保存的成功或不可用结果；版本或输入变化使旧叙事不可复用，未核对叙事不进入恢复点。报告到期时间不超过原会话窗口，失败与取消不静默发布部分结果为完整报告。
- 聚焦回归覆盖原误拒与错误放行、缺证/部分/执行失败区分、假引用和错摘录、无关论点/摘要、坏支持响应、供应商失败、期限与取消、已验证叙事恢复、完整报告复用，以及长文全部事实/条件/引用保留。旧版独立性、固定篇章和易读再次调用的重复测试已由这些行为约束替换；PIT、单位、投资建议边界与原评分约束继续执行。

## 2026-09-08 事实选择与联合核验 2.0

- 上述旧生成语义仅用于历史读取。新模型只选择当前快照的事实键，程序绑定引用与完整原始陈述；评分事实限定到对应维度，同列表稳定去重。支持与反证可以同源，但联合核验必须确认不同支持和限制含义，可靠性按去重来源计算。
- 正常路径为研究候选、评分候选、联合支持核验三次逻辑调用。没有直接反证不单独阻断论点，编译内容明确披露缺口；看多、看空及综合判断仍须分别有可核验依据。评分理由允许事实支持的数字、单位及期间，语义否定仅排除对应论点或维度，不循环补写整稿。
- 私有 JSONB checkpoint 1.2 保存结构化候选与联合裁决；输入、生成版本和校验版本全部匹配才复用。候选不公开，取消、期限与迟到写入保护保持。报告/论点 2.0；历史 1.x schema 保持原件，旧 API 无法无损表达时明确返回投影不可用。
- 新报告及部分结果通过既有 /api/v2 下的版本化读取入口消费，继续使用同一服务、存储和 Markdown 编译。页面、打印和下载显示相同反证缺口、局部未评分原因及合成身份。
- 六维分档、乘 25 与权重不变，六维有效才计算总分。合成计算系数为 1、真实证据可信度为 0，不能进入真实公司排名。B 组独立案例按固定证券 ID 绑定来源版本，原 v3/v4 不变，不新增真实采集或公开测试参数。

## 2026-09-08 真实资料采集与独立审核

- 本节取代新研究使用合成/混合预览、单一 Pro 路由和一次业务补证的运行决定。真实私人研究从空事实包开始，Flash 分别规划搜索及提取原文，Pro 使用独立调用核对主体、业务、数字、单位、期间、摘录与冲突；随后复用研究、评分、联合支持核验三次调用。历史报告不改写，合成资料仅允许离线开发与测试入口。
- 复用现有 coordinator、Tavily、SourceConnectorPort、LLMProviderPort、JSONB checkpoint 和跨 worker 配额，不新增服务或表。每项一次初次采集和最多三次额外尝试；权限阻断、取消和期限优先。候选与未完成审核留在私有 checkpoint，只有通过项进入研究；身份和主营业务未核实时停止资料阶段。
- 实际预览模板目前托管的取数服务为 Tavily，未配置可直接供该研究入口消费的财务 API。财务等维度必须取得合格网页或公告原文，否则保留真实缺口；不能把离线 API 名称或已有库安装视作接口取数成功。
- 新增 `pypdf==6.18.0`，许可证 BSD-3-Clause；版本、wheel 和 sdist 的 SHA256 已锁定。官方提取说明：https://pypdf.readthedocs.io/en/stable/user/extract-text.html；许可证：https://github.com/py-pdf/pypdf/blob/main/LICENSE。与已有 Docling 候选相比，本任务只需文本 PDF，不启用 OCR、VLM 或额外模型权重。抓取上限 12 MiB，提取上限 350 页、单页内容流 2 MiB、文本 100000 字符；独立无凭据进程限制 CPU、内存及 12 秒墙钟时间。扫描、加密、无文本及超限输入均不猜数。
- PDF 保留页码及布局文本；Flash 与 Pro 读取同一有界上下文，事实位置由程序从原文定位。数字摘录必须有原文数值、单位和期间，表格跨列关系由独立审核检查，不能把“文字可提取”冒称“表格已可靠理解”。
- 真实当前研究可将无 Last-Modified 的版本记录为实际抓取时观察到的版本，不伪造历史修订时间；显式历史研究仍禁止实时采集。巨潮 `static.cninfo.com.cn/finalpage/YYYY-MM-DD/…PDF` 仅提供公告日期时，按上海该日日末保守校验并在来源标签说明精度，不能推定日内发布时间。其他未知发布日期继续保持缺口。
- 本轮来源登记扩展至启用的交易所、巨潮和监管页面，核实的五家公司官网，以及路透、证券时报和上海证券报。授权仍为本轮 `DEV_ONLY/UNVERIFIED` 私人研究；Pro 通过不改变来源身份。没有独立核验的转载或多个媒体域名不提高为独立多来源可靠性。
- 新报告 2.1 与 runtime config 1.1；历史 1.x/2.0 报告和 runtime config 1.0 冻结。checkpoint 1.3 按证券、输入、请求截点、截止时间、规则及来源登记匹配。页面、下载和打印共用编译后的审核说明、原文位置及缺口。
