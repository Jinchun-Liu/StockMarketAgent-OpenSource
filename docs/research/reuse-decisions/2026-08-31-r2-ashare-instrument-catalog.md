# R2 沪深北 A 股证券目录复用决策

日期：2026-08-31
状态：`accepted_for_private_dev_preview`
生产权利状态：`DEV_ONLY/UNVERIFIED`

## 能力缺口

R2 的搜索适配器此前只有十条手工示例，无法支持用户按任意当前 A 股代码或简称创建研究；其中还把真实
证券 `600000` 错标为合成停牌样本。公共 `InstrumentMasterDataPort 1.1` 已足以表达搜索和解析，缺口
首先是其离线 provider 的目录覆盖。严格 1.0 搜索响应保持不变；需要显式公司全称核验状态的新 Web
通过 `InstrumentMasterDataV2Port` 与并列的目录搜索响应 1.1 opt-in，不修改旧 Port 或旧响应语义。
不需要数据库或运行时网络调用。

## 调研与选择

- 采用仓库已锁定的 AKShare `1.18.70`，在人工显式刷新命令中复用上交所、深交所和北交所当前及沪深
  退市目录 adapter；代码许可证为 MIT，上游目录权利分别绑定三家交易所的官方法律声明。
- 三家交易所法律声明均允许在遵守声明和法律的前提下基于非商业目的浏览、下载网站内容。项目据此只
  登记私有非商业预览的证券代码、简称、上市/退市日期等白名单元数据 `FETCH + RETAIN`；不登记商业、
  公开再分发、全文、embedding 或训练权利。
- 不自行重写三个交易所的 XLSX/分页协议。现有 adapter 已完成字段解析，重复实现会增加 schema drift
  和反爬差异，但不会提升权利状态。
- 不在搜索请求、API 启动、测试或 worker 中访问上述网络。显式生成器把规范身份写成版本化 JSON，运行时
  只读该快照并继续执行 PIT 截点校验。
- 不采用 Tushare 或商业证券主数据作为搜索目录，因为当前私有预览无需新增凭据、付费依赖或另一组来源
  契约；生产前仍需重新完成正式授权、shadow trial 与 live E2E。

## 固定快照

`resources/instruments/ashare-catalog.dev.v1.json.gz` 固定于
`ashare-directory.dev.v1.1.20260831`，共 5,884 条规范身份：上交所主板/科创板、深交所主板/创业板、
北交所当前列表以及沪深历史退市目录。快照保存各来源 URL、抓取时间、记录数和规范化源内容哈希；
还保存精确权利记录哈希、允许操作、用途和保留截止时间；不保存行情、财务、持仓、网页正文、搜索摘要
或凭据。生成器先校验权利再联网，命令行不再允许人为回填抓取时间。

上交所当前目录提供已核验公司全称；深交所、北交所和历史退市目录只把官方证券简称作为可搜索显示名，并显式记录
`legal_name_verified=false`。前端不得把重复的简称伪装成已核验公司全称。北交所 `430047` 仅作为
既有 R2 示例的旧代码别名，规范结果返回当前 `XBSE:920047`。

旧的 5,888 条聚合口径多算了四个已换码但主体连续存续的证券。交易所公告证明：`000022 → 001872`
（深赤湾A/招商港口）、`000043 → 001914`（中航善达/招商积余）、`300114 → 302132`
（中航电测/中航成飞）、`600849 → 601607`（上海医药）。当前 5,884 条目录只保留换码后的规范身份，
把旧代码与名称登记为可搜索别名；这既保留历史查找能力，也避免同一上市主体被重复研究。固定快照的
交易所/状态计数为 `XSHG=2,461`、`XSHE=3,084`、`XBSE=339`、`active=5,551`、`delisted=333`，测试
同时锁定三份原始目录回执数，防止用降低下限掩盖缺项。

换码事实不再只是代码里的 URL 字符串。`configs/sources.yaml` 另行登记深交所和上交所代码变更公告
来源及 `allowed_hosts`；生成器在访问前执行同一 rights gate，拒绝跨白名单重定向，并为四份固定公告
保存 `evidence_id`、真实抓取时间、内容 SHA-256、权利快照 SHA-256、URL 和保留截止时间。公告正文
只在显式生成期间用于计算哈希，不写入仓库。每个规范证券记录反向保存对应 evidence ID，运行时校验
四条证据、来源回执和别名引用闭合。

## 边界

该快照只供私有 R2 开发预览。官方声明支持本轮非商业下载，但不证明公开再分发、模型训练、商业使用或
生产时效资格。界面继续显示非生产标识；四项 `PRODUCTION_*` 门禁保持阻断。目录每条 revision 的
`known_at` 等于真实抓取时间，早于该时间的历史截点必须返回不可见；正式目录刷新必须追加 revision 并
完成生产 PIT/权利审计，不得把本快照静默解释为实时主数据。运行时每次 `resolve/search/query` 都检查
快照保留截止时间，过期后失败关闭，不复用进程缓存绕过保留策略。
